# Atelier

A working console for an independent artist's business — pricing, outreach, portfolio,
line sheet, and market research in one place.

**Live:** https://orphanheiress.github.io/Atelier/

Access is gated. The gate is client-side only, so treat it as casual privacy rather than
real security.

## What's in it

- **Start here** — where things stand and the next moves
- **Outreach** — designer and trade contacts, with drafted messages
- **Lookbook** — the works, with story fields and copy-ready listings
- **Line sheet** — print-ready sheet for sending to designers and curators
- **Price** — the pricing ladder, floor vs market, and a per-piece calculator
- **Toolkit** — sales psychology research and mockup guidance

Plain HTML, CSS, and JavaScript. No build step, no dependencies, no backend.
All data lives in the browser's local storage, so nothing leaves the device.
Export and import are available for moving data between devices.

## Running it locally

Open `index.html` in a browser. That's the whole setup.
